自媒体工作台 · 浏览器插件

把工作台常驻浏览器侧边栏，关掉网页也能收到「该发了 / 已逾期」提醒

侧边栏常驻今日速览后台提醒数据不出本机

这个插件能做什么

侧边栏常驻完整工作台嵌入浏览器右侧栏，刷网页、写稿时一抬眼就能改排期、记待办
今日速览点工具栏图标，今日待发、逾期未发、逾期待办，一秒看完今天要干什么
后台系统提醒到发布时点还没标「发了」→ 弹通知；工具栏角标实时显示今日待处理数

第一步：下载插件

适用于 Chrome / Edge 等 Chromium 浏览器 · 约 18 KB · 文件保存在浏览器默认下载目录

第二步：加载到浏览器（1 分钟）

  1. 解压刚才下载的压缩包，得到一个文件夹
  2. 地址栏输入 chrome://extensions 回车（Edge 用 edge://extensions）
  3. 打开页面右上角的「开发者模式」开关
  4. 点「加载已解压的扩展程序」，选择第 1 步解压出的文件夹
  5. 工具栏出现紫色列表图标即安装成功，点它就能看到今日速览
关于数据 数据只存在浏览器本地，插件不建服务器、不传任何数据上网。插件后台读取的是网页版每次保存时广播的只读快照——先在侧边栏或标签页里用一次工作台（任何改动都会触发保存），后台才有数据可提醒。侧边栏内嵌的是线上版页面，与平时打开的数据完全一致。
