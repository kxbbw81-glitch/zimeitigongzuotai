# 浏览器插件（常驻 + 后台提醒）

把自媒体工作台搬到浏览器侧边栏常驻，关掉网页也能收到「该发了 / 已逾期」的系统通知。

## 安装（Chrome / Edge，1 分钟）

1. 地址栏输入 `chrome://extensions` 回车（Edge 用 `edge://extensions`）
2. 打开右上角的「**开发者模式**」开关
3. 点「**加载已解压的扩展程序**」，选择本目录（`extension` 文件夹）
4. 工具栏出现紫色列表图标即安装成功

## 获取插件

- **压缩包方式**：下载「自媒体工作台-浏览器插件.zip」→ 解压 → 按上面步骤选择解压出来的文件夹
- **线上安装页**（一键下载 + 图文步骤）：https://media-workbench-64130.app.workbuddy.host/plugin-install.html

## 三个入口

| 入口 | 作用 |
|---|---|
| 点工具栏图标 | 「今日速览」弹窗：今日待发 / 逾期未发 / 逾期待办，一眼看完 |
| 速览里点「打开侧边栏」 | 完整工作台常驻右侧，刷网页时一抬眼就能改数据 |
| 速览里点「打开工作台」 | 新标签页打开完整版 |

## 提醒规则（与站内口径一致）

- **该发了**：今天排期、已到发布时间、还没标「发了」→ 系统通知
- **逾期未发**：排期日期已过、未发布 → 每天汇总提醒一次
- **逾期待办**：待办日期已过、未完成 → 每天汇总提醒一次
- 工具栏图标角标 = 今日待处理总数（待发 + 逾期 + 逾期待办）
- 每 30 分钟检查一次；同一条同一天只响一次，不重复轰炸

## 数据说明（重要）

- **数据仍然只存在浏览器本地**，插件不建服务器、不传任何数据上网
- 插件后台读的是网页版每次保存时广播的快照（chrome.storage），**只读**
- 所以：先在侧边栏/标签页里用一次工作台（任何改动都会触发保存），后台才有数据可提醒
- 侧边栏内嵌的是线上版页面，与平时打开的数据完全一致（同一 origin）

## 卸载

`chrome://extensions` 里点「移除」即可，浏览器里的工作台数据不受影响。
