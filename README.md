# 外贸社媒 + 自媒体一体化工作台

> 一站式社媒内容工作台：**从灵感到发布，一个页面走完全流程**——国内自媒体与国外外贸社媒（TikTok / Instagram / Facebook / YouTube / LinkedIn / X…）共用同一套排期、素材、数据和账本。
>
> 纯前端单页应用（vanilla JS）· 无构建 · 无后端 · 无外部依赖 · 双击 `index.html` 即可使用 · 数据只存在本机浏览器

**在线体验**：https://media-workbench-64130.app.workbuddy.host/

---

## 它解决什么问题

做内容的人的一天是碎片的：灵感散在各处、排期靠脑记、发了没有、数据补没补、哪个选题能打、素材到底用了哪张图——这些散事没有一件值得开一个专业软件，但合起来就是持续的消耗。做外贸社媒的还多一层：国内外几个平台来回倒，同一篇内容要改几个版本，发布节奏和数据各在各的后台。

社媒工作台把这条动线收进一个页面：**今天该干什么 → 内容从哪来 → 什么时候发 → 发之前差什么 → 发完之后效果如何 → 顺带把账算清**。侧边栏按「今天 / 做内容 / 发出去 / 看效果 / 日常」五组一字排开，12 个模块各管一段，互不迷路。

## 六个核心竞争力

### 1. 账号 IP 是内容生产的总输入，不是档案袋

大多数工具里账号信息填完就完了。这里不一样：选中某个账号后，**定位、目标受众、内容风格、表达风格、内容聚焦、内容配比这六项会原样进入每一次 AI 生成的上下文**——改其中一个字，选题工厂造题的比例、AI 文案的语气、智能排期的铺法全都跟着变。

- **内容配比**（案例 / 方法 / 工具 / 复盘）决定选题工厂按什么比例造题；账号卡把「目标配比」和「实际产出」画在一起对比，偏差超 15 个百分点标橙；已发不足 5 篇时只显示目标，不拿假百分比误导你
- **国内外平台一把抓**：内置国内 7 个 + 国外外贸社媒 11 个平台，下拉自动分组；列表里没有的选「自定义平台…」自建名称和标识色——账号卡、平台筛选、发布提醒、AI 生成上下文全都认
- **内容聚焦**一行一个方向，每条内容都能标方向；账号页统计每个方向「已发几篇、库存几篇、最近何时发过」，哪个方向在空转一眼看穿；点方向直接跳去 AI 文案台并把方向填进主题
- **AI 识别导入**：把任何 AI 帮你写好的账号资料整段粘贴进去，自动拆出平台、账号名、定位、风格、聚焦、粉丝等字段，认不出来的明确列出来提醒手填，不覆盖已填内容

### 2. 素材库：文件在你自己硬盘上

选一个文件夹（比如 `D:\社媒素材库`），之后：

- 自动建好 **图片 / 视频 / 音频 / 文章 / 模板** 五个子文件夹，新素材按扩展名自动归位；文件名里有日期的优先按文件名标日期
- **不复制、不上传、不转存任何文件**——只存一份索引和你打的标签；标签写成文件夹里的 `.mw-assets.json`，跟着文件夹走，换电脑、清缓存都不丢
- 内容与素材**双向关联**：发布页给内容「绑素材」，素材页显示「N 条内容在用」并可点开反查——换过的封面、复用过的图，都有据可查
- 「从清单移除」只删索引不动文件；「永久删除」才真删硬盘文件，且必须二次确认
- Chrome / Edge 直接读写文件夹；Safari / Firefox 自动降级为手动登记，只记位置不影响用

### 3. 发布管理：排完期到发出去，中间那段

日历回答「哪天发」，发布管理回答「今天能不能发、还差什么、发完没」。四项发布前检查点一下就勾；点「发了」时才真正推进状态——内容变已发布、关联选题在看板同步、记下实际发布时间。页面按 **今天要发 / 逾期未发 / 待补数据 / 未来 7 天** 四个桶组织，底部「本周发布节奏」按各账号更新频率对比实发量，谁掉队一眼看到。每行还带该平台的发布提醒（小红书靠封面、公众号靠开头 100 字）。

### 4. 财务：一笔订单记一行，利润自动算

记的是订单不是流水：客户是谁、卖的什么项目、收多少、本钱多少，利润自己算。来源渠道记客户从哪来，收款渠道记钱怎么收的，底部两张排行直接告诉你哪个渠道、哪门生意最赚钱。运营开销记在支出流水页签，口径完整：**营收 − 成本 = 毛利，毛利 − 运营支出 = 净利**。已有 Excel 账本的不用手敲——复制粘贴进导入框，自动认列、订单号去重、预览后再入账。收入红、支出绿，符合国内记账习惯。

### 5. AI 长在每个模块里，且不配置也能用

需要的地方直接有按钮，不用先去 AI 页面再回来：今日页「AI 补排期」、看板「AI 补选题」、灵感「AI 扩写 / 二创」、复盘「AI 诊断 / AI 复盘」。

侧边栏「AI 接口」内置 **21 个服务商预设**，分三组：

- **国内常用（10）**：智谱 GLM（glm-4-flash 有免费额度，默认选中）、DeepSeek、通义千问、Kimi、豆包、腾讯混元、文心一言、MiniMax、讯飞星火、硅基流动
- **国外（7）**：OpenAI、Claude、Gemini、Grok、Mistral、Groq、OpenRouter
- **本地模型（4）**：Ollama、LM Studio、vLLM、LocalAI——无需密钥、完全离线

选一个就自动填好接口地址和推荐模型，附直达开放平台的密钥获取链接；也支持任意 OpenAI 兼容中转网关（选「自定义」）。**不配置 AI 也能用**——所有功能都有本地降级方案（本地公式选题、本地模板文案、本地数据诊断）。

### 6. 预警主动找你，不等你来找它

断更天数（阈值由账号周更频率决定，更得越勤提醒越早）、选题库存不足 3 个、已发布超过一天没录数据——今日页顶部红色提示。插件装上也行：**关掉网页也能收到「该发了 / 已逾期」的系统通知**。

## 浏览器插件：常驻 + 后台提醒

`extension/` 目录是一个 Chrome / Edge 扩展（Manifest V3），加载后：

| 入口 | 作用 |
|---|---|
| 点工具栏图标 | 「今日速览」弹窗：今日待发 / 逾期未发 / 逾期待办，一秒看完 |
| 速览里点「打开侧边栏」 | 完整工作台常驻浏览器右侧，刷网页时一抬眼就能改数据 |
| 后台定时检查 | 每 30 分钟一次；到发布时点没标「发了」弹系统通知，逾期每天汇总一次，工具栏角标显示今日待处理数 |

提醒规则与站内口径完全一致（未发布 = 没标「发了」、逾期 = 排期日期已过、待办完成 = 打了勾），同一条同一天只响一次。插件不建服务器、不传数据上网，后台读的只是网页版保存时广播的只读快照。

安装与详细说明见 [`extension/README.md`](extension/README.md)，或访问线上安装页 https://media-workbench-64130.app.workbuddy.host/plugin-install.html 一键下载。

三种方式数据都在各自浏览器本地，互不干扰；换设备用「导出备份 / 导入备份」同步。

## 数据与隐私

- 所有数据保存在浏览器 localStorage（键 `mw_db_v1`），**不联网、不上传、无任何服务端**
- 素材文件永远在你自己的硬盘上，工作台只存索引和标签
- 设置页支持导出 JSON 备份 / 导入恢复；误操作可「恢复示例」
- 2 人以上团队建议每天下班前导出一次，通过网盘或即时通讯同步

## 技术特性

- **零依赖**：vanilla JS（ES5 兼容）、无构建、无框架、无 npm 包，`file://` 协议直接可用
- **零后端**：hash 路由 + localStorage，数据库结构版本化（当前 v6），老数据自动迁移不丢失
- **响应式**：桌面多列网格，≤900px 侧栏自动改滑出抽屉，看板手机端单列，四档宽度（1360 / 1024 / 768 / 390）零文档级横向溢出
- **工程纪律**：保存写时间戳防多标签页覆盖；不静默失败；删硬盘文件二次确认；所有图标内联 SVG

## 常见问题

**Q：数据存在哪，换电脑怎么办？**
A：存在浏览器 localStorage。设置页「导出备份」生成 JSON，新电脑导入即可；素材文件夹本身可以整体拷贝或走网盘同步。

**Q：Safari / Firefox 能用吗？**
A：网页版全部功能可用；素材库的「直接读写文件夹」需要 Chrome / Edge（File System Access API），其他浏览器自动降级为手动登记路径，不影响其他模块。

**Q：AI 一定要配密钥吗？**
A：不必须。不配则所有 AI 功能走本地降级（本地公式选题、本地模板文案）。配了就用真模型，本地模型（Ollama 等）连密钥都不需要。

**Q：插件和网页版是什么关系？**
A：插件是外壳，内核还是这个网页。侧边栏里嵌的就是线上版页面，数据 origin 一致、完全互通；插件额外提供常驻入口和后台系统通知。
