# 自媒体工作台

面向自媒体博主的一站式内容工作台。纯前端单页应用（vanilla JS），无构建、无后端、无外部依赖，双击 index.html 即可使用，数据保存在浏览器 localStorage。

## 功能模块

- 今日作战台 / 灵感雷达 / 选题工厂 / 内容看板 / AI 文案
- 内容日历 / 发布管理（发布前检查清单 + 素材绑定）
- 数据复盘 / 同行对标
- 待办 / 财务（订单式）/ 账号 IP 管理
- 素材库（本地文件夹模式：File System Access + IndexedDB + 旁车文件）

## AI 接口

侧边栏「AI 接口」内置 21 个服务商预设（国内 10 / 国外 7 / 本地 4），兼容任意 OpenAI 兼容接口；不配置也有本地降级方案。

## 本地运行

浏览器直接打开 index.html，或放到任意静态托管。

## 浏览器插件（常驻 + 后台提醒）

`extension/` 目录是一个 Chrome / Edge 扩展（MV3）：加载后工作台常驻侧边栏，
关掉网页也能收到「该发了 / 已逾期」系统通知，工具栏图标显示今日待处理数。
安装与说明见 [`extension/README.md`](extension/README.md)。

## 数据说明

- 所有数据在浏览器本地（localStorage），不上传
- 设置页支持导出 / 导入备份
